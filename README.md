# Public Skills

A collection of agent skills for Claude Code, Cursor, and other AI coding tools.

| Skill | What it does |
|---|---|
| [benchmarking-implementations](benchmarking-implementations/SKILL.md) | Before committing to a technical approach, check how established codebases model similar behavior, APIs, state, tests, and edge cases. |
| [creating-pull-requests](creating-pull-requests/SKILL.md) | Create well-structured pull requests with clear descriptions and review-ready branches. |
| [NIH-principle-checker](NIH-principle-checker/SKILL.md) | Avoid not-invented-here custom builds by checking libraries, SDKs, managed services, internal platforms, gateways, and vendor APIs. |
| [mining-pr-guidelines](mining-pr-guidelines/SKILL.md) | Mine historical PR review comments to turn recurring feedback into written coding guidelines. |
| [subagent-orchestrator](subagent-orchestrator/SKILL.md) | Coordinate multi-step work by delegating research, debugging, and tasks to subagents with isolated context. |
